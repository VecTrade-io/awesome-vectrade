# Contributing to Awesome VecTrade

## Guidelines

### Adding a project

1. Make sure the project is related to VecTrade
2. Add it to the relevant section in alphabetical order
3. Use the format: `[project-name](url) — Brief description`
4. One project per PR

### Quality standards

- Project should have a README
- Project should be actively maintained (last commit within 6 months)
- SDKs should pass basic functionality tests
- No abandoned or broken projects

### Categories

- **Community SDKs** — Client libraries in any language
- **AI Framework Integrations** — LangChain, CrewAI, AutoGen, etc.
- **Example Projects** — Runnable demos and tutorials
- **Tools & Utilities** — CLI tools, GitHub Actions, monitoring, etc.
- **Content & Tutorials** — Blog posts, videos, courses

## Process

1. Fork this repo
2. Add your project to README.md
3. Submit a PR with a brief description of what the project does
4. Wait for review (usually < 48h)
