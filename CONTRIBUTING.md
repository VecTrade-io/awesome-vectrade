# Contributing to Awesome VecTrade

Thank you for contributing! This document explains the process and requirements for adding entries to this list.

## Guidelines

### Before Submitting

- Search existing entries to avoid duplicates.
- Ensure the project is related to VecTrade or financial data tooling that integrates with VecTrade.
- The project should have a README with clear documentation.

### Quality Standards

- **Actively maintained** — last commit within 6 months.
- **Working** — project should install and run without errors.
- **Documented** — clear README with usage instructions.
- **Licensed** — must have an open-source license.
- **No duplicates** — check existing entries first.

### Entry Format

Use the following format for all entries:

```markdown
- [project-name](https://github.com/owner/project) — Brief description ending with a period.
```

Rules:
- Description starts with a capital letter.
- Description ends with a period.
- No trailing whitespace.
- One entry per line.
- Alphabetical order within each section.

### Categories

| Category | What belongs here |
|----------|------------------|
| **Community SDKs** | Client libraries in any language |
| **AI & MCP Integrations** | LangChain, CrewAI, AutoGen, MCP tools |
| **Tools & Utilities** | CLI tools, GitHub Actions, monitoring, dashboards |
| **Example Projects** | Runnable demos, templates, starter kits |
| **Content & Tutorials** | Blog posts, videos, courses, talks |

### What NOT to Add

- Paid/proprietary tools without a free tier.
- Projects that don't work or are clearly abandoned.
- Self-promotional spam.
- Duplicate entries or minor forks of existing projects.

## Process

1. Fork this repository.
2. Add your entry to the appropriate section in `README.md`.
3. Ensure your entry follows the format guidelines above.
4. Submit a Pull Request with:
   - A clear title (e.g., "Add vectrade-rust community SDK").
   - A brief description of what the project does.
5. Wait for review (usually < 48 hours).

## Updating Existing Entries

If a project has moved, been renamed, or is no longer maintained:

1. Open an issue describing the change.
2. Or submit a PR with the fix.

## Code of Conduct

Be respectful and constructive. We follow the [Contributor Covenant](https://www.contributor-covenant.org/).
