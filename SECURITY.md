# Security Policy

## Reporting a Vulnerability

This repository contains only curated links (an awesome-list). It does not contain executable code.

If you discover a security issue with a linked project, please report it directly to the project maintainers.

For issues with the VecTrade platform:

- **Email:** security@vectrade.io
- **Subject:** `[SECURITY] <brief description>`

We will acknowledge receipt within 48 hours.
